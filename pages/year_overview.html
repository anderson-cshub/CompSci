Year 10 Curriculum Overview

Systems Architecture

Knowledge

Students understand the purpose of the CPU and the fetch–execute cycle, and are familiar with the components of the CPU (ALU, CU, cache, registers). They understand the Von Neumann architecture, including the roles of the MAR, MDR, program counter and accumulator, and recognise the purpose and characteristics of embedded systems. They know the impact of common CPU characteristics such as clock speed, cache size and number of cores on performance, and the function and role of various registers in the CPU.

Skills

Students describe and explain the stages of the fetch–execute cycle, identify and label CPU components and explain their functions, and explain how the Von Neumann architecture stores and processes data. They can code using assembly language, analyse how clock speed, cache size and number of cores affect CPU performance, differentiate between the roles of various registers (such as the program counter and accumulator), and identify examples of embedded systems, describing how they process data and produce output. They apply knowledge to scenarios involving embedded systems and their components.

Key Terms

CPU (Central Processing Unit), ALU (Arithmetic Logic Unit), CU (Control Unit), cache, MAR (Memory Address Register), MDR (Memory Data Register), program counter, accumulator, embedded systems.

Summative Assessment

Written assessment — end of topic test.

Memory and Storage — Part 1

Knowledge

Students understand the need for primary storage in computer systems and the difference between RAM and ROM, including their characteristics (volatile and non‑volatile). They understand the purpose and function of virtual memory, the need for secondary storage and the types of devices used (optical, magnetic, solid‑state), and how common types of secondary storage store data (magnetism, semiconductor chips, etc.). They know the advantages and disadvantages of different storage media and devices, and the purpose of tertiary storage for backups and data archiving.

Skills

Students differentiate between RAM and ROM and explain their purposes, illustrate how virtual memory functions and why it is needed, and explain scenarios where virtual memory is used and how it affects system performance. They compare storage devices in terms of capacity, speed, portability, durability, reliability and cost, evaluate storage devices for specific applications, and create visual comparisons (e.g. flowcharts or Top Trump cards) based on device characteristics. They make recommendations for the most suitable storage devices based on user needs and explain how secondary storage complements primary storage in computer systems.

Key Terms

RAM (Random Access Memory), ROM (Read‑Only Memory), virtual memory, secondary storage, optical storage, magnetic storage, solid‑state storage, tertiary storage.

Memory and Storage — Part 2

Knowledge

Students understand units of data storage (bit, nibble, byte, kilobyte, megabyte, gigabyte, terabyte, petabyte) and the necessity of converting data into binary format for computer processing. They can calculate data capacity requirements for storage, perform binary addition and understand overflow errors, convert between binary and hexadecimal and between denary and hexadecimal, and understand how character sets (ASCII, Unicode) are represented in binary. They understand how images are represented in binary and the effect of colour depth and resolution, how sound is sampled and stored digitally, and the importance of compression (lossy and lossless) for reducing file size.

Skills

Students convert between different units of data storage, perform binary–denary–hexadecimal conversions, add binary integers and interpret overflow errors, and apply binary shifts to manipulate data. They calculate file sizes for images and audio based on colour depth, resolution, bit depth and sample rate, explain how sound is sampled and stored digitally, and compare lossy and lossless compression techniques and their impact on quality and file size.

Key Terms

Bit, byte, nibble, binary, denary, hexadecimal, overflow error, character set, ASCII, Unicode, pixel, metadata, compression, lossy, lossless.

Summative Assessment

Written assessment — end of topic test with multiple‑choice questions on Microsoft Forms.

Computer Networks

Knowledge

Students understand different types of networks, including LAN (Local Area Network) and WAN (Wide Area Network), and factors that affect network performance such as bandwidth, error rate and latency. They know the role of hardware in connecting computers to a network (routers, switches, NICs), the difference between client–server and peer‑to‑peer models, and common network topologies such as star and mesh. They understand the internet as a global network, including DNS, hosting and cloud computing, and wired (Ethernet) and wireless (Wi‑Fi, Bluetooth) modes of connection. They also learn about encryption, IP addressing (IPv4, IPv6), MAC addressing, network protocols (TCP/IP, HTTP, HTTPS, FTP, POP, IMAP, SMTP) and the concept of layering in networking.

Skills

Students describe and illustrate the differences between LAN and WAN, analyse how network performance is impacted by different factors, and set up and configure network hardware such as routers and wireless access points. They differentiate between client–server and peer‑to‑peer models and explain their use cases, compare the advantages and disadvantages of star and mesh topologies, and explain how the internet works, including the role of DNS, IP addresses and hosting. They recommend appropriate network connection modes for different scenarios, configure network encryption, apply and explain common network protocols, and illustrate how layering simplifies network design and maintenance.

Key Terms

LAN, WAN, bandwidth, latency, router, switch, IP address, MAC address, TCP/IP, HTTP, HTTPS, FTP, POP, IMAP, SMTP, protocol, encryption, DNS, cloud computing.

Summative Assessment

Written assessment — end of topic test with multiple‑choice questions on Microsoft Forms.

Network Security

Knowledge

Students understand different forms of attack: malware, social engineering, brute‑force attacks, denial‑of‑service (DoS), data interception and SQL injection. They recognise the risks posed by social engineering, including phishing and people as a weak point, and understand the purpose of brute‑force attacks and how to recognise and prevent them. They learn how DoS attacks work and how to protect against them, the role of SQL injection in data theft and how to protect databases, and common network security measures such as penetration testing, anti‑malware, firewalls, encryption and physical security. They also understand the importance of user access levels, passwords and two‑factor authentication for system security.

Skills

Students identify different forms of cyberattack and explain how each one works, explain how social engineering exploits human behaviour, and identify and prevent brute‑force attacks by implementing password policies. They apply techniques such as firewalls and traffic filtering to prevent DoS attacks, implement validation and security checks to prevent SQL injection, and explain and apply various security measures to protect systems from attacks. They implement user access levels and strong password policies, use different types of security software and hardware, and conduct penetration testing to identify vulnerabilities and improve system security.

Key Terms

Malware, phishing, brute‑force attack, denial‑of‑service (DoS), SQL injection, encryption, firewall, penetration testing, anti‑malware, physical security, user access levels, two‑factor authentication.

Systems Software

Knowledge

Students understand the purpose and functionality of operating systems, including user interfaces, memory management, peripheral management and file management. They know different types of user interfaces (GUI, CLI, natural language, menu interfaces), how operating systems handle multitasking and memory management, the role of drivers in peripheral management, and the importance of user management (logins and permissions). They understand file management and how the OS organises, moves and edits files, and the purpose and functionality of utility software, including encryption, defragmentation and data compression.

Skills

Students describe how operating systems manage hardware and software resources efficiently, compare and explain the features and uses of different types of user interfaces, and demonstrate how multitasking works while explaining how the OS manages memory and processes. They explain how operating systems use drivers to manage communication between software and peripherals, manage user access and permissions to ensure security and efficiency, and use file management features to organise, edit and manage files and folders. They use and explain utility software to maintain and optimise system performance, and apply encryption, defragmentation and data compression techniques to improve system security and efficiency.

Key Terms

Operating system, user interface, GUI, CLI, multitasking, drivers, user management, file management, utility software, encryption, defragmentation, data compression.

Summative Assessment

Written assessment — written exam assessed as part of the end‑of‑year exam.

Year 11 Curriculum Overview

Algorithms

Knowledge

Principles of computational thinking: abstraction, decomposition, and algorithmic thinking. Inputs, processes, and outputs of a problem and how they relate to algorithms. Structure diagrams and their use in visualising problem‑solving processes. Pseudocode, flowcharts, and high‑level languages for creating, interpreting, and refining algorithms. Standard searching algorithms: linear search and binary search. Standard sorting algorithms: bubble sort, merge sort, and insertion sort. Identifying common errors in algorithms and fixing them. Understanding and correcting algorithms through debugging and refining steps. Using trace tables to track variable changes and detect errors in algorithms. Correcting and refining algorithms to ensure efficiency and accuracy.

Skills

Applying abstraction to simplify complex problems. Using decomposition to break down problems into smaller parts. Creating and interpreting structure diagrams. Writing pseudocode and creating flowcharts. Implementing linear and binary search algorithms and comparing their efficiency. Developing and applying sorting algorithms (bubble, merge, insertion). Using trace tables to track variable changes and detect errors. Correcting and refining algorithms to ensure efficiency and accuracy.

Key Terms

Abstraction, decomposition, algorithmic thinking, pseudocode, linear search, binary search, bubble sort, merge sort, insertion sort, trace table.

Assessment

Written Assessment — End of topic test (MCQ on MS Forms).

Knowledge

Boolean operators: AND, OR, NOT. Representing logic gates in diagrams and interpreting outputs. Using truth tables to represent and evaluate logic gate outputs. Combining Boolean operators to two levels (e.g., (A OR B) AND C). Application of Boolean logic in solving problems and decision‑making. Identifying how Boolean logic is used in digital circuits and computer systems.

Skills

Constructing logic diagrams using AND, OR, NOT. Creating and interpreting logic gate diagrams. Completing and interpreting truth tables. Applying Boolean operators to two levels in diagrams and truth tables. Solving problems using logic diagrams and truth tables. Designing circuits and systems using Boolean logic.

Key Terms

AND, OR, NOT, truth table, logic gate, Boolean expression.

Differentiating between high‑level and low‑level languages. Writing and translating code using assemblers, compilers, interpreters. Using IDE features like code completion, error diagnostics, debugging tools. Translating source code into machine code and explaining how translation affects execution speed and efficiency.

Writing programs using variables, constants, operators. Implementing sequence, selection, iteration. Using arithmetic and Boolean operators. Applying data types correctly and performing type casting. Manipulating strings. Handling files. Using records and SQL queries. Using arrays (1D and 2D). Creating structured programs using functions and procedures. Writing programs using random numbers.

Variable, constant, operator, sequence, selection, iteration, string manipulation, file handling, SQL, array (1D/2D), function, procedure, random number generation.
