Three Constructs

Output

print is the command word for an output. That is all it does — it outputs to the screen. 


print("hello world")

Input

Inputs allow the user to enter their own data. We store this data in a variable.

A variable is a piece of storage in memory. Its value can change during the program.

This is a common exam point: variables can change, constants cannot. 


name = input("Enter your name: ")
print("Hello", name)

Input + Output Example

A simple program that asks for two numbers, adds them, and prints the result. 


num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

total = num1 + num2

print(f"The total is {total}")

The Three Constructs of Programming

All algorithms — from simple GCSE pseudocode to full A Level programs — are built from three fundamental constructs: Sequence, Selection, and Iteration. Mastering these makes every other topic easier.

Sequence

Sequence means instructions run in a specific order, one after another. This is the simplest construct and forms the backbone of all algorithms.

  • GCSE: Describe the order of steps.
  • A Level: Understand data flow and side effects.
  • Used everywhere — input, processing, output.
# Example (Python)
name = input("Name: ")
age = int(input("Age: "))
print(f"Hello {name}")
print(f"You are {age}")

Selection

Selection allows algorithms to make decisions. IF, ELSE, ELIF, SWITCH — choosing different paths based on conditions.

  • GCSE: IF / ELSE statements.
  • A Level: Nested selection, boolean logic, switch/match.
  • Used for validation, branching logic, error handling.
# Example (Python)
if age >= 18 and has_id:
    print("Entry allowed")
else:
    print("Entry denied")

Iteration

Iteration repeats instructions until a condition is met. FOR loops, WHILE loops, DO‑WHILE loops, recursion.

  • GCSE: Count‑controlled and condition‑controlled loops.
  • A Level: Loop invariants, recursion, termination conditions.
  • Used for searching, sorting, processing lists, simulations.
# Example (Python)
for i in range(1, 6):
    print(i)

# Recursive example
def countdown(n):
    if n == 0:
        print("Go!")
    else:
        print(n)
        countdown(n - 1)
