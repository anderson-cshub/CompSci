Three Constructs

Sequence

Instructions executed in a specific order, one after another. This is the foundation of all algorithms — the flow of steps. 

# Runs line 1 → 2 → 3
name = input("Name: ")
age = int(input("Age: "))
print(age)

A Level: Sequence also includes calling subroutines and returning to the main program.

Selection

Decision‑making in algorithms. IF, ELSE, ELIF — choosing different paths based on a condition. 

age = 17
if age >= 18:
    print("Adult")
else:
    print("Child")

OCR often calls this branching.

Iteration

Repetition of instructions. FOR loops - repeat a fixed amount of times, WHILE loops — repeating until a condition is met. 

for i in range(1, 4):
    print(i)

Recursion is A Level only and is covered separately.

The Three Constructs of Programming

All algorithms — from simple GCSE pseudocode to full A Level programs — are built from three fundamental constructs: Sequence, Selection, and Iteration. Mastering these makes every other topic easier.

Sequence

Sequence means instructions run in a specific order, one after another. This is the simplest construct and forms the backbone of all algorithms.

  • GCSE: Describe the order of steps.
  • A Level: Understand data flow and side effects.
  • Used everywhere — input, processing, output.

# Example (Python)
name = input("Name: ")
age = int(input("Age: "))
print(f"Hello {name}")
print(f"You are {age}")

Selection

Selection allows algorithms to make decisions. IF, ELSE, ELIF, SWITCH — choosing different paths based on a condition.

  • GCSE: IF / ELSE statements.
  • A Level: Nested selection, boolean logic, switch/match.
  • Used for validation, branching logic, error handling.

# Example (Python)
age = 17

if age >= 18 and has_id:
    print("Entry allowed")
else:
    print("Entry denied")

Iteration

Iteration repeats instructions until a condition is met. FOR loops, WHILE loops, DO‑WHILE loops, recursion.

  • GCSE: Count‑controlled and condition‑controlled loops.
  • A Level: Loop invariants, recursion, termination conditions.
  • Used for searching, sorting, processing lists, simulations.

# Count-controlled loop
for i in range(1, 6):
    print(i)

# Recursion (A Level only)
def countdown(n):
    if n == 0:
        print("Go!")
    else:
        print(n)
        countdown(n - 1)
