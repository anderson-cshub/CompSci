Lists and Arrays

Lists in Python

A list is Python’s main way of storing multiple values. Lists are dynamic — you can add, remove, or change items whenever you like. 

scores = [10, 20, 30, 40]
print(scores[0])  # first item
scores.append(50)

Lists are used everywhere in Python because they are flexible and easy to work with.

Lists can hold mixed data types and change size at runtime - you can add to the list dynamically, so you don't need to program the size of the list.

Accessing Elements

Use indices to access or update elements in lists or arrays. Remember that the first number in Computer science is Zero (0), so the first element is held in position 0. 

scores = [10, 20, 30]
scores[1] = 20

print(scores)  
# Would output: [10, 20, 30]

print(*scores)  
# Would output: 10 20 30

Append (Add an Item)

append() adds a new item to the end of a list. This is one of the most important GCSE list operations. 

scores = [10, 20, 30]
scores.append(40)
print(scores)  # [10, 20, 30, 40]

Append = add to the end of the list.

Remove (Delete an Item)

remove() deletes the first matching value from a list. Another essential GCSE operation. 

scores = [10, 20, 30]
scores.remove(20)
print(scores)  # [10, 30]

Remove = delete by value.

Insert (Add at a Position)

insert() places a new item at a specific index. 

scores = [10, 30, 40]
scores.insert(1, 20)
print(scores)  # [10, 20, 30, 40]

Insert = add at a chosen index.

Length of a List

Use len() to count how many items are in a list. 

scores = [10, 20, 30, 40]
print(len(scores))  
# 4

Length = number of items.

Count Items in a List

count() tells you how many times a value appears. 

scores = [10, 20, 10, 30, 10]
print(scores.count(10))  
# 3

Count = how many times a value appears.

Find an Item’s Index

index() returns the position of a value in the list. 

names = ["Alice", "Bob", "Charlie"]
print(names.index("Bob"))  
# 1

Index = position of an item.

Print an Item Using Its Index

Access items directly using square brackets. 

names = ["Alice", "Bob", "Charlie"]
print(names[2])  
# Charlie

Indexing = access by position.

Pop (Delete by Index)

pop() removes an item using its index and returns it. 

scores = [10, 20, 30]
removed = scores.pop(1)
print(removed)  
# 20

print(scores)  
# [10, 30]

Pop = delete by index.

Arrays (GCSE Concept)

In GCSE pseudocode, an array is a fixed‑size structure. Once you choose the size, it cannot grow or shrink, and every element must be the same data type. 

# Example GCSE pseudocode
DECLARE scores[5] AS INTEGER
scores[0] ← 10
scores[1] ← 20

Arrays in GCSE are used for exam questions and theory — they do not behave like Python lists.

Arrays are fixed in size (usally hard-coded) and fixed in data type ie. only strings or only integers — unlike Python lists.

2D Arrays — Tic‑Tac‑Toe Example

A 2D array stores data in rows and columns. Each element is accessed using two indices: [row][column]. 

grid = [
    ["X", "O", "X"],
    ["O", "X", "O"],
    ["X", " ", "O"]
]

print(grid[0][2])  # top‑right cell

Each row represents a line on the board; each column a position.

2D Arrays — Pupil Scores (X/Y Explanation)

We can think of a 2D array like a map using X and Y co‑ordinates. In Python lists, the row comes first (Y), then the column (X).

Rows (Y): Alice = 0, Bob = 1, Charlie = 2 Columns (X): Name = 0, Subject = 1, Score = 2 

results = [
    ["Alice", "Maths", 88],
    ["Bob", "Science", 75],
    ["Charlie", "English", 92]
]

print(results[0][0])  # Alice
print(results[0][1])  # Alice’s subject
print(results[0][2])  # Alice’s score

print(results[1][0])  # Bob
print(results[1][1])  # Bob’s subject
print(results[1][2])  # Bob’s score

Row = pupil, column = data field.

2D Arrays — Pupil Scores (GCSE Explanation)

A 2D array stores data in rows and columns. Each row represents a pupil, and each column holds a data field such as name, subject, or score. 

results = [
    ["Alice", "Maths", 88],
    ["Bob", "Science", 75],
    ["Charlie", "English", 92]
]

print(results[0][0])  # Alice
print(results[0][1])  # Alice’s subject
print(results[0][2])  # Alice’s score

Rows are pupils (0 = Alice, 1 = Bob, 2 = Charlie). Columns are data fields (0 = Name, 1 = Subject, 2 = Score). 

print(results[1][0])  # Bob
print(results[1][1])  # Bob’s subject
print(results[1][2])  # Bob’s score

Row = pupil, column = data field.
