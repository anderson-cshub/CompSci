Numbers

Numbers are used for calculations, measurements, rounding, and mathematical operations. Python supports integers, real numbers, and a range of operators.

Integers

Whole numbers with no decimal places.

age = 15
score = 100
lives = 3

Real Numbers (Floats)

Numbers with decimal places.

price = 19.99
height = 1.82
temperature = 23.5

Getting Numbers from Input

Use int() or float() to convert text input into numbers.

age = int(input("Enter your age: "))
price = float(input("Enter the price: "))

print("Next year you will be", age + 1)

Operators

Basic arithmetic operators.

a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...

Exponent (Power)

Python uses ** for powers.

print(2 ** 3)   # 8
print(5 ** 2)   # 25

Rounding

Round to the nearest whole number.

print(round(3.6))   # 4
print(round(3.2))   # 3

Round Up & Down

Use math.ceil and math.floor.

import math

print(math.ceil(4.1))   # 5
print(math.floor(4.9))  # 4

Decimal Places

Round to a specific number of decimal places.

print(round(3.14159, 2))   # 3.14
print(round(3.14159, 4))   # 3.1416

MOD (Remainder)

% gives the remainder after division. It does not tell you how many times it goes in. 

print(12 % 3)   # 0  (12 ÷ 3 = 4, remainder 0)
print(10 % 3)   # 1  (3 * 3 = 9, remainder 1)
print(9 % 3)    # 0
print(12 % 10)  # 2  (10 goes in once, remainder 2)
print(25 % 4)   # 1

DIV (Integer Division)

// gives the whole number part of division (no decimals). 

print(10 // 3)   # 3   (3 * 3 = 9)
print(25 // 4)   # 6   (6 * 4 = 24)
print(12 // 10)  # 1

Random Numbers

Use the random module to generate random integers, floats, and choices.

import random

num1 = random.randint(1, 10)
print("Random integer 1–10:", num1)
num2 = random.uniform(1.0, 5.0)
print("Random float 1.0–5.0:", num2)
choice = random.choice([10, 20, 30])
print("Random choice:", choice)

Common Misconception — Using ^ for Powers

Many students think Python uses ^ for exponents. In Python, ^ is actually the bitwise XOR operator. 

print(2 ^ 3)   # 1 (XOR, not 8!)

The correct operator for powers is **. 

print(2 ** 3)   # 8

Common Misconception — Random Numbers

Pupils often forget that random functions require the random module. Without import random, none of the functions will work.

Correct version:

import random
num = random.randint(1, 10)
print(num)

Common incorrect versions:

num = randint(1, 10)  
# ❌ randint is not defined without import random

num = random(1, 10)  
# ❌ random() does not take arguments — use randint()

num = random.randint(1, 10  
# ❌ missing closing bracket

Another misconception is thinking randint(1,10) excludes 10. It actually includes both ends of the range. 

print(random.randint(1, 10))  
# could be 1, 10, or anything in between

Common Misconception — MOD Gives “How Many Times”

A common mistake is thinking MOD tells you how many times a number goes into another. It actually gives the remainder. 

print(10 % 3)   # 1  (remainder)
print(12 % 10)  # 2
print(9 % 3)    # 0

MOD is especially useful for checking if a number is even, odd, or divisible by another number. 

num = 12

print(num % 2)   # 0 → even
print(num % 5)   # 2 → not divisible by 5

Common Mistake — Missing Brackets in int(input())

Pupils often forget a bracket when converting input to an integer. Editors highlight matching brackets to help you spot mistakes.

Correct version:

num = int(input("Enter a number: "))
print("You typed", num)

Common incorrect versions:

num = int(input("Enter a number: ")   # ❌ missing closing ) for int()

num = int"Enter a number: "))   # ❌ extra ) and wrong syntax

In most editors, when you click next to a bracket, the matching bracket lights up. If one side does not highlight, you are probably missing a bracket.
