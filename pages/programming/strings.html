Strings

Strings are pieces of text. Python lets you join them together, change their case, check what they contain, and extract parts of them. They are one of the most important data types in programming.

Joining Text Together (Concatenation)

You can join strings using the + operator.

first = "Computer"
second = "Science"

print(first + second)        # ComputerScience
print(first + " " + second)  # Computer Science

Concatenation only works with strings. Joining text with numbers causes an error.

Using Variables Inside Text (f‑strings)

f‑strings are the modern, recommended way to combine text and variables. They let you insert variables directly into a sentence using { }.

name = "Mr Anderson"
age = 15

print(f"Hello {name}")          # Hello Mr Anderson
print(f"You are {age} years old")

f‑strings automatically convert numbers to text.

Uppercase & Lowercase

name = "Mr Anderson"

print(name.upper())   # MR ANDERSON
print(name.lower())   # mr anderson

Useful for checking input (e.g. making comparisons case‑insensitive).

Length of a String

word = "computer"
print(len(word))   # 8

The len() function counts characters.

Left, Right & Middle (Slicing)

Python doesn’t have LEFT/RIGHT like pseudocode — instead, it uses slicing.

word = "computer"

print(word[0:3])   # com   (LEFT 3)
print(word[-3:])   # ter   (RIGHT 3)
print(word[3:6])   # put   (MIDDLE)

Slicing uses [start:end] — end is not included.

Split

sentence = "I love computer science"
words = sentence.split()

print(words)   # ['I', 'love', 'computer', 'science']

Split turns a string into a list of words.

Contains

word = "computer"

print("put" in word)     # True
print("dog" in word)     # False

Use in to check if text appears inside a string.

Replace

text = "I love cats"
print(text.replace("cats", "dogs"))

Replace swaps one piece of text for another.

ASC & CHR (ASCII Codes)

print(ord('A'))   # 65   (ASC)
print(chr(65))    # A    (CHR)

Use ord() to get ASCII numbers, and chr() to convert back.

Common Misconception

Students often try to “add” strings and numbers together:

age = 15
print("You are " + age)   # ❌ ERROR

Python cannot join text and numbers directly.

Correct versions:

print("You are " + str(age))        # casting
print(f"You are {age}")              # f-string (recommended)

Use str() or f‑strings when mixing text and numbers.
