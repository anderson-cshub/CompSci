Strings

Strings are pieces of text. Python lets you join them, split them, search inside them, change their case, and extract parts of them. This page shows the most important string operations using clear examples.

Concatenation

Joining strings using +.

first = "Computer"
second = "Science"

print(first + second)        # ComputerScience
print(first + " " + second)  # Computer Science

f‑Strings

Insert variables directly into text using { }.

name = "Mr Anderson"
age = 15

print(f"Hello {name}")
print(f"You are {age} years old")

Upper / Lower

Change the case of a string.

name = "Mr Anderson"

print(name.upper())   # MR ANDERSON
print(name.lower())   # mr anderson

Length

len() counts characters, including spaces.

word = "computer"
print(len(word))   # 8

phrase = "Mr Anderson"
print(len(phrase)) # 11

Slicing

Extract parts of a string using [start:end].

word = "computer"

print(word[0:3])   # com
print(word[-3:])   # ter
print(word[3:6])   # put

Split

Break a string into words. Creates a list.

sentence = "I love computer science"
words = sentence.split()

print(words)    # ['I','love','computer','science']
print(words[2]) # computer

Contains

Check if text appears inside a string.

word = "computer"

print("put" in word) # True
print("dog" in word) # False

Replace

Swap one piece of text for another.

text = "I love cats"
print(text.replace("cats", "dogs"))

ASC / CHR

Convert between characters and ASCII numbers.

print(ord('A')) # 65
print(chr(65))  # A

Common Misconception — Mixing Text and Numbers

A very common mistake is trying to join text (a string) with a number (an integer) using the + operator. Python cannot do this. 

age = 15
print("You are " + age)   # ❌ ERROR

Python does not automatically convert numbers to text. You must either:

  • convert the number using str()
  • or use an f‑string, which handles the conversion automatically
print("You are " + str(age))
print(f"You are {age}")
