Strings

Strings are pieces of text. Python lets you join them together, change their case, check what they contain, and extract parts of them. They are one of the most important data types in programming.

Joining Text Together (Concatenation)

Concatenation means joining strings together. Python uses the + operator to join text. 


first = "Computer"
second = "Science"

print(first + second)        # ComputerScience
print(first + " " + second)  # Computer Science

Concatenation only works when both sides are strings. If you try to join text with a number, Python throws an error.

Using Variables Inside Text (f‑strings)

f‑strings let you insert variables directly into text using { }. They are cleaner and avoid the need for str(). 


name = "Mr Anderson"
age = 15

print(f"Hello {name}")          
print(f"You are {age} years old")

Python automatically converts numbers to text inside an f‑string.

Uppercase & Lowercase

These functions change the case of a string. Useful for comparisons (e.g. making user input case‑insensitive). 


name = "Mr Anderson"

print(name.upper())   # MR ANDERSON
print(name.lower())   # mr anderson

Length of a String

len() counts how many characters are in a string. This includes letters, numbers, punctuation, and spaces. 


word = "computer"
print(len(word))   # 8

phrase = "Mr Anderson"
print(len(phrase)) # 11 (includes the space)

Left, Right & Middle (Slicing)

Python uses slicing instead of LEFT/RIGHT. Slicing uses [start:end] — the first number is where to begin, the second number is where to stop (but the stop position is not included). 


word = "computer"

print(word[0:3])   # com   (characters 0,1,2)
print(word[-3:])   # ter   (last 3 characters)
print(word[3:6])   # put   (characters 3,4,5)

Python starts counting at 0, not 1.

Split

split() breaks a string into pieces and stores them in a list. By default, it splits wherever it finds a space. 


sentence = "I love computer science"
words = sentence.split()

print(words)        # ['I', 'love', 'computer', 'science']
print(words[0])     # I
print(words[2])     # computer

The numbers [0], [1], [2] refer to positions in the list.

Contains

Use in to check if text appears inside a string. 


word = "computer"

print("put" in word)     # True
print("dog" in word)     # False

Replace

replace() swaps one piece of text for another. 


text = "I love cats"
print(text.replace("cats", "dogs"))

ASC & CHR (ASCII Codes)

ord() gives the ASCII number of a character. chr() converts a number back to a character. 


print(ord('A'))   # 65
print(chr(65))    # A

Common Misconception

Students often try to “add” strings and numbers together:

age = 15
print("You are " + age)   # ❌ ERROR

Python cannot join text and numbers directly.

Correct versions:

print("You are " + str(age))        # casting
print(f"You are {age}")              # f-string (recommended)

Use str() or f‑strings when mixing text and numbers.
